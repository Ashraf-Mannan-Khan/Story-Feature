# 📸 Stories Feature App

A modern Instagram-style Stories feature built with React.  
Users can upload image stories, view them in fullscreen, swipe between stories, and stories automatically expire after 24 hours.

## ✨ Features

- 📱 Mobile-first responsive design
- 🖼 Upload and preview image stories
- ⏳ Stories automatically expire after 24 hours
- 🔄 Auto-progress story animation
- 👉 Swipe left/right to navigate between stories
- ✋ Tap left/right area to move next/previous
- 💾 Persistent storage using LocalStorage
- 🎯 Smooth animations & transitions
- 🌙 Modern dark UI design

---

## 🛠 Tech Stack

- ⚛ React
- 🎨 CSS3 (Flexbox / Responsive Design)
- 📦 LocalStorage API
- 🖱 Touch & Pointer Events

---

## 🧠 How It Works

### 1️⃣ Upload Story
- User selects an image
- Image is converted to Base64
- Stored in LocalStorage with a timestamp

### 2️⃣ Story Viewer
- Opens in fullscreen modal
- Progress bar auto-animates
- Automatically switches to next story
- Swipe gesture supported

### 3️⃣ Expiration Logic
- On app load, stories older than 24 hours are filtered out
- Expired stories are removed automatically
